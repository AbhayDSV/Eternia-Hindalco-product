## 🚀 Quick Start

1. Open http://localhost:5173
2. Use any of the credentials above
3. Explore role-specific dashboards and features

## 📋 Testing Scenarios

### Fabricator Flow
1. Login as fabricator
2. View dashboard with order statistics
3. Click "Create Order"
4. Fill order details and add items
5. Save as draft or submit

### Supply Chain Flow
1. Login as supply chain
2. View pending approvals
3. Approve or refer back orders
4. Manage ranking and allocation

### Admin Flow
1. Login as admin
2. Access all modules
3. Manage users and master data
4. Monitor system health
